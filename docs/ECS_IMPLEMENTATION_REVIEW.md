# Seeded shuffle, Undo и replay на ECS — итог ревью

Изменения подготовлены в `feature/deterministic-board` для объединения в `develop`.
Архитектура остаётся основанной на ECS.

## Что работает в коде

- Начальная раскладка воспроизводится по seed, размеру, скрытому тайлу и числу шагов.
- Состояние партии и история принадлежат ECS-сущности поля.
- Отмена последнего хода возвращает предыдущее состояние и корректирует историю.
- Просмотр истории текущей незавершённой партии идёт на отдельном поле.
  «Стоп» возвращает текущее игровое поле даже посреди анимации.
- После просмотра можно продолжить играть. Энергия и награды просмотром не меняются.
- Существующие тайлы получают координаты из модели; анимация больше не меняет правила игры.
- В игровом экране добавлена панель «Отмена», «Повтор/Стоп», число ходов и seed.

## Исправления повторного ревью

- Проверки replay теперь проверяют каждый промежуточный расклад, координаты плиток,
  ожидание анимации и остановку уже начавшегося движения.
- Presenter форматирует строку только при изменении seed, числа ходов или позиции replay.
- `BoardControlsView` хранит сериализованные ссылки на кнопки и подписи в prefab;
  создание GameObject и оформление удалены из runtime-кода.
- Проекция поля запускается по `BoardChangedEvent` и при создании отображения.
  Перебор плиток на каждом пустом кадре удалён.
- `ReplayData.CreatePlaybackBoard()` явно проверяет путь на копии и возвращает
  стартовое поле. Повторное перемешивание перед воспроизведением удалено.

## Проверки и ограничения

- В процессе исправлений прошли 74 NUnit-теста и 59 проверок сервисов/ECS с заменами Unity API.
- Итоговая проверка по просьбе владельца ограничена компиляцией: Domain, тесты,
  игровой runtime и Editor-код компилируются с библиотеками Unity 6000.0.71f1.
- Финальные PlayMode, визуальная проверка и Android-сборка отложены по просьбе владельца.
- [Порядок ручной проверки](BOARD_STATE.md#manual-acceptance-in-unity).
- Replay относится к текущей незавершённой партии; сохранение записей, просмотр
  после экрана результата, импорт и обмен кодом остаются следующим этапом.
- CI автоматически запускает тесты Domain на Linux/Windows; Android в workflow не входит.

Визуальный стиль Riverside Village сохранён отдельным коммитом. Обновления ресурсов
TMP/URP и настроек графики для Unity 6 также сохраняются отдельно.
Резервные файлы `.bak-*` перенесены из Assets в локальную служебную папку.
