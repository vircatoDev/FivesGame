# Тесты

158 тестов в трёх сборках Unity. 33 доменных теста дополнительно запускаются без Unity, в GitHub Actions на каждый push.

## Как запустить

| Что | Команда | Где работает |
|---|---|---|
| Доменные тесты (33) | `dotnet test tools/domain-tests/Tests/Fives.Domain.Tests.csproj` | без Unity; в CI на Linux и Windows |
| Все тесты (158) | Window → General → Test Runner → EditMode → Run All | в редакторе Unity |
| Все тесты из терминала | `tools/unity.sh test` (редактор должен быть закрыт) | Unity в batch mode, итог в терминале |
| Формат префабов и сцен | `python3 tools/check_unity_text.py` | без Unity; в CI |

CI не запускает тесты Unity: для них нужна лицензия Unity. Перед слиянием изменений в `Assets/Scripts` прогоните `tools/unity.sh test`.

Проверка формата не разбирает YAML Unity целиком. Она ловит пустые строки и нетекстовые файлы в префабах и сценах:
такая ошибка сериализации однажды стёрла ссылки `BoardControlsView`. Тесты Unity она не заменяет.

## Где что лежит

```
Assets/Tests/
  Domain/        Fives.Domain.Tests      правила поля и экономики, чистый C#
  Runtime/       Fives.Runtime.Tests     системы ECS, сервисы и презентеры на фейках
    Setup/         стенд игры, партия на поле 4×3, фейки
    Board/         ввод, подсказка, панель хода
    Run/           начало и конец партии, победа
    Boot/          экран загрузки: скачивание тем
    Menu/          меню, старт партии
    Economy/       звёзды, энергия, награда, баланс
    Saving/        сохранение, язык, громкость
    Screens/       навигация между экранами
  EditorUI/      Fives.UI.Editor.Tests   проверки ассетов: переводы, шрифт, ссылки, манифест, вёрстка
  Support/       Fives.Tests.Support     TestScreenView для теста навигатора
```

`Support` — отдельная сборка не для редактора: Unity не прикрепляет MonoBehaviour из сборок, которые собираются только для редактора.

В Test Runner тесты сгруппированы так же, как папки: `Fives.Runtime.Tests.Board`, `Fives.Runtime.Tests.Menu` и так далее.

## Как написать тест

- **`GameStand`** (`Runtime/Setup`). Сервисы игры собраны так же, как в `GameLifetimeScope`, но сохранение хранится в памяти, часы тестовые, а экраны заменены фейками. Каждый сервис создаётся при первом обращении, поэтому конфиг и сохранение можно поменять до этого. Презентеры создаются методами `MainMenu(view)`, `SelectMenu(view)`, `Result()` и `GamePlay()`.
- **`BoardFixture`**. Партия на поле 4×3: сущность поля с плитками, `Swipe`, `Tap`, `Control` и `Settle`. Системы подключаются по требованию, для хода и победы есть `WithGameplaySystems()`.
- **`TestConfig`**. Стартовые значения: 200 звёзд, 5 энергии, награда 10 звёзд, подсказка за 5, тема `cities` за 60, тема `dogs` открыта. Ожидаемые числа записывайте через эти константы, а не готовыми числами.
- **`Allocations`**. `Allocations.During(action)` считает выделения памяти в потоке теста, пока выполняется действие. Проверку «кадр не выделяет память» пишите так: `Assert.That(Allocations.During(systems.Run), Is.Zero)`. `Is.Not.AllocatingGCMemory()` из Unity здесь не подходит: он иногда засчитывает тесту выделение памяти в другом потоке, и тест падает случайно.

```csharp
[Test]
public void ThemePurchase_DebitsOnce_EvenWhenTappedTwice()
{
    using var game = new GameStand();
    var select = game.SelectMenu(new FakeSelectMenuView());

    select.OnThemeBuy("cities");
    select.OnThemeBuy("cities");

    Assert.That(game.Stars.GetBalance(), Is.EqualTo(TestConfig.Stars - TestConfig.CitiesPrice));
}
```

## Правила

- Папка соответствует фиче, пространство имён повторяет папку, в файле один тестовый класс с тем же именем.
- Имя теста — предложение: что происходит, при каком условии и чем кончается, например `Undo_DuringAnimation_IsIgnored`.
- У каждого теста есть комментарий `/// <summary>` на русском: какой сценарий он проверяет и чем тот должен закончиться. У строк `[TestCase]` — короткий комментарий, чем эта строка отличается от остальных.
- Тест проверяет поведение, которое видят игрок или другие части игры, а не внутреннее устройство системы.
- Каждое правило проверяется в одном месте. Правило домена — в `Domain`; через сервис проверяется только то, что добавляет сам сервис.
- Поле в тестах 4×3, как в игре.
- Новый файл создавайте из Unity или добавляйте вместе с его `.meta`, иначе Unity присвоит файлу новый GUID.
